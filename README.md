# RPG Character

A simple Python application that creates an RPG character with a name and three character stats: Strength, Intelligence, and Charisma.

## Features

- Validates the character name
- Ensures the character has a name
- Limits character names to 10 characters
- Prevents spaces in character names
- Validates that all stats are integers
- Ensures each stat is between 1 and 4
- Ensures the total starting stats equal 7 points
- Displays character stats using full and empty dots

## Example

```python
create_character("ren", 4, 2, 1)
